\subsubsection{Objetivos}\label{objetivos}

Antes de começar as unidades, você precisa deixar o computador pronto.
Ao final desta preparação, você terá:

\begin{itemize}
\tightlist
\item
  \textbf{Python 3} instalado e funcionando;
\item
  um \textbf{ambiente virtual} isolado para o curso;
\item
  as \textbf{bibliotecas} (spaCy, pandas, scikit‑learn, matplotlib,
  Jupyter);
\item
  o \textbf{modelo de linguagem} do spaCy baixado;
\item
  os \textbf{dados} (corpus) na pasta certa;
\item
  os \textbf{exercícios} rodando com correção automática.
\end{itemize}

\begin{tipbox}

\textbf{Dica:} faça esta preparação \textbf{uma vez}. Depois, sempre que
for estudar, basta \textbf{ativar o ambiente virtual} (passo 2) e
começar.

\end{tipbox}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{1. Python 3}\label{python-3}

O curso usa \textbf{Python 3.9 ou mais novo}. Verifique se já tem, no
terminal:

\begin{Shaded}
\begin{Highlighting}[]
\ExtensionTok{python3} \AttributeTok{{-}{-}version}
\end{Highlighting}
\end{Shaded}

Se aparecer algo como \texttt{Python\ 3.11.x}, está pronto. Se não tiver
Python, baixe em
\href{https://www.python.org/downloads/}{python.org/downloads}
(Windows/macOS) ou instale pelo gerenciador do seu sistema (no macOS,
via \href{https://brew.sh}{Homebrew}: \texttt{brew\ install\ python}).

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{2. Ambiente virtual (venv)}\label{ambiente-virtual-venv}

Um \textbf{ambiente virtual} isola as bibliotecas do curso, sem bagunçar
o resto do sistema. Crie um na pasta do curso:

\begin{Shaded}
\begin{Highlighting}[]
\ExtensionTok{python3} \AttributeTok{{-}m}\NormalTok{ venv .venv}
\end{Highlighting}
\end{Shaded}

E \textbf{ative‑o} (você repete este passo toda vez que for estudar):

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# macOS / Linux}
\BuiltInTok{source}\NormalTok{ .venv/bin/activate}

\CommentTok{\# Windows (PowerShell)}
\ExtensionTok{.venv\textbackslash{}Scripts\textbackslash{}Activate.ps1}
\end{Highlighting}
\end{Shaded}

Quando ativo, o nome \texttt{(.venv)} aparece no início da linha do
terminal. Para sair, use \texttt{deactivate}.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{3. Instalar as bibliotecas}\label{instalar-as-bibliotecas}

Com o ambiente \textbf{ativado}, atualize o \texttt{pip} e instale tudo
de uma vez:

\begin{Shaded}
\begin{Highlighting}[]
\ExtensionTok{pip}\NormalTok{ install }\AttributeTok{{-}{-}upgrade}\NormalTok{ pip}
\ExtensionTok{pip}\NormalTok{ install }\AttributeTok{{-}r}\NormalTok{ requirements.txt}
\end{Highlighting}
\end{Shaded}

Se preferir instalar manualmente:

\begin{Shaded}
\begin{Highlighting}[]
\ExtensionTok{pip}\NormalTok{ install spacy pandas scikit{-}learn matplotlib jupyterlab}
\end{Highlighting}
\end{Shaded}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{4. Baixar o modelo de linguagem do
spaCy}\label{baixar-o-modelo-de-linguagem-do-spacy}

O spaCy separa a biblioteca do \textbf{modelo} treinado. As Unidades 2 e
3 usam o modelo \textbf{pequeno} de inglês; a Unidade 5 usa o
\textbf{médio}:

\begin{Shaded}
\begin{Highlighting}[]
\ExtensionTok{python} \AttributeTok{{-}m}\NormalTok{ spacy download en\_core\_web\_sm}
\ExtensionTok{python} \AttributeTok{{-}m}\NormalTok{ spacy download en\_core\_web\_md}
\end{Highlighting}
\end{Shaded}

Teste se carregou:

\begin{Shaded}
\begin{Highlighting}[]
\ExtensionTok{python} \AttributeTok{{-}c} \StringTok{"import spacy; nlp = spacy.load(\textquotesingle{}en\_core\_web\_sm\textquotesingle{}); print(\textquotesingle{}spaCy OK\textquotesingle{})"}
\end{Highlighting}
\end{Shaded}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{5. Os dados (corpus)}\label{os-dados-corpus}

Os exemplos usam alguns arquivos de texto (notícias) e uma planilha de
comentários (o corpus \textbf{SOCC}). Coloque‑os numa pasta chamada
\texttt{data/}, ao lado dos seus notebooks:

\begin{verbatim}
data/
  NYT_1991-01-16-A15.txt
  WP_1990-08-10-25A.txt
  WP_1991-01-17-A1B.txt
  socc_gnm_articles.csv
\end{verbatim}

Esses arquivos vêm do material do curso de referência \emph{Applied
Language Technology} --- repositório em
\href{https://github.com/Applied-Language-Technology}{github.com/Applied-Language-Technology}.
Baixe‑os de lá e salve na pasta \texttt{data/}.

\begin{notebox}

\textbf{Nota:} os caminhos no material (ex.:
\texttt{open(\textquotesingle{}data/NYT\_1991-01-16-A15.txt\textquotesingle{})})
supõem que você está rodando o Python \textbf{na pasta que contém
\texttt{data/}}.

\end{notebox}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{6. Rodar os exemplos}\label{rodar-os-exemplos}

Cada unidade traz blocos de código para você experimentar. A forma mais
confortável é o \textbf{Jupyter}:

\begin{Shaded}
\begin{Highlighting}[]
\ExtensionTok{jupyter}\NormalTok{ lab}
\end{Highlighting}
\end{Shaded}

Isso abre o Jupyter no navegador; crie um notebook novo e cole os blocos
de código da unidade, executando célula por célula
(\texttt{Shift\ +\ Enter}). Você também pode salvar o código em um
arquivo \texttt{.py} e rodar com \texttt{python3\ arquivo.py}.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{7. Rodar os exercícios (correção
automática)}\label{rodar-os-exercuxedcios-correuxe7uxe3o-automuxe1tica}

Cada unidade tem um conjunto de exercícios com \textbf{testes
automáticos}, na pasta \texttt{exercicios/}. Edite o arquivo da unidade
(ex.: \texttt{unidade1\_exercicios.py}), substituindo cada
\texttt{todo(...)} pela sua solução, e rode:

\begin{Shaded}
\begin{Highlighting}[]
\BuiltInTok{cd}\NormalTok{ exercicios}
\ExtensionTok{python3} \AttributeTok{{-}m}\NormalTok{ unittest unidade1\_test}
\end{Highlighting}
\end{Shaded}

Quando aparecer \texttt{OK}, você acertou todos. Enquanto houver
\texttt{todo(...)}, o teste falha de propósito.

\begin{tipbox}

\textbf{Bom saber:} os testes dos exercícios usam \textbf{só a
biblioteca padrão} do Python --- não precisam do spaCy nem do pandas.
Assim, eles rodam em qualquer lugar, inclusive em corretores automáticos
como o \textbf{Judge0}.

\end{tipbox}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{Checklist final}\label{checklist-final}

Antes de ir para a Unidade 1, confirme:

\begin{itemize}
\tightlist
\item[$\square$]
  \texttt{python3\ -\/-version} mostra \textbf{3.9 ou mais novo}
\item[$\square$]
  o ambiente virtual está \textbf{ativado} (\texttt{(.venv)} aparece no
  terminal)
\item[$\square$]
  \texttt{pip\ install\ -r\ requirements.txt} rodou sem erros
\item[$\square$]
  \texttt{python\ -c\ "import\ spacy;\ spacy.load(\textquotesingle{}en\_core\_web\_sm\textquotesingle{})"}
  imprime \textbf{spaCy OK}
\item[$\square$]
  a pasta \texttt{data/} contém os arquivos do corpus
\item[$\square$]
  \texttt{python3\ -m\ unittest\ unidade1\_test} roda (mesmo que os
  exercícios ainda falhem)
\end{itemize}
