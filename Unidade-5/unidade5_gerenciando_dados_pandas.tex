\subsubsection{Objetivos de
aprendizagem}\label{objetivos-de-aprendizagem}

Ao final desta unidade, você deverá saber:

\begin{itemize}
\tightlist
\item
  \textbf{importar dados} para um \texttt{DataFrame} do pandas;
\item
  \textbf{explorar} dados armazenados em um \texttt{DataFrame};
\item
  \textbf{acrescentar} (estender) dados a um \texttt{DataFrame};
\item
  \textbf{salvar} os dados de um \texttt{DataFrame}.
\end{itemize}

O \textbf{pandas} é uma biblioteca do Python para trabalhar com
\textbf{dados tabulares}. Começamos importando‑a --- usamos \texttt{as}
para controlar o nome do módulo importado; por convenção, o pandas é
abreviado como \texttt{pd}:

\begin{Shaded}
\begin{Highlighting}[]
\ImportTok{import}\NormalTok{ pandas }\ImportTok{as}\NormalTok{ pd}
\end{Highlighting}
\end{Shaded}

\subsubsection{1.1 A partir de um único
arquivo}\label{a-partir-de-um-uxfanico-arquivo}

Formatos típicos para distribuir corpora incluem arquivos \textbf{CSV}
(\emph{Comma‑separated Values}, valores separados por vírgula),
\textbf{JSON} (\emph{JavaScript Object Notation}) e texto simples. O
pandas oferece muitas funções para ler dados em vários formatos --- dá
até para importar planilhas do Excel!

O exemplo a seguir carrega um recorte do \emph{SFU Opinion and Comments
Corpus} (SOCC), que reúne artigos de opinião do jornal canadense
\emph{The Globe and Mail}. Usamos a função \texttt{read\_csv()}, que
recebe uma \emph{string} com o \textbf{caminho} do arquivo:

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Lê o arquivo CSV e atribui a saída a variável \textquotesingle{}socc\textquotesingle{}}
\NormalTok{socc }\OperatorTok{=}\NormalTok{ pd.read\_csv(}\StringTok{\textquotesingle{}data/socc\_gnm\_articles.csv\textquotesingle{}}\NormalTok{)}

\CommentTok{\# Examina o tipo do objeto guardado em \textquotesingle{}socc\textquotesingle{}}
\BuiltInTok{type}\NormalTok{(socc)}
\end{Highlighting}
\end{Shaded}

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{pandas.core.frame.DataFrame}
\end{Highlighting}
\end{Shaded}

O pandas faz todo o trabalho pesado e devolve o conteúdo do CSV em um
\textbf{\texttt{DataFrame}}, a estrutura de dados nativa do pandas.
Usamos o método \texttt{head()} para ver as primeiras cinco linhas:

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Imprime as primeiras cinco linhas do DataFrame}
\NormalTok{socc.head(}\DecValTok{5}\NormalTok{)}
\end{Highlighting}
\end{Shaded}

\texttt{article\_id}, \texttt{title}, \texttt{author},
\texttt{article\_text} etc., além de um \textbf{índice} para cada linha
(0, 1, 2, \ldots). Uma versão compacta (algumas colunas omitidas para
caber):

\subsubsection{1.2 A partir de múltiplos
arquivos}\label{a-partir-de-muxfaltiplos-arquivos}

Outro cenário comum é ter \textbf{vários arquivos} de texto para
carregar. Primeiro, coletamos os arquivos com a classe \texttt{Path}
(vista na Unidade 1):

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Importa a classe Path}
\ImportTok{from}\NormalTok{ pathlib }\ImportTok{import}\NormalTok{ Path}

\CommentTok{\# Cria um objeto Path que aponta para o diretório com os dados}
\NormalTok{corpus\_dir }\OperatorTok{=}\NormalTok{ Path(}\StringTok{\textquotesingle{}data\textquotesingle{}}\NormalTok{)}

\CommentTok{\# Coleta todos os arquivos .txt no diretório do corpus}
\NormalTok{corpus\_files }\OperatorTok{=} \BuiltInTok{list}\NormalTok{(corpus\_dir.glob(}\StringTok{\textquotesingle{}*.txt\textquotesingle{}}\NormalTok{))}

\CommentTok{\# Verifica os arquivos do corpus}
\NormalTok{corpus\_files}
\end{Highlighting}
\end{Shaded}

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{[PosixPath(\textquotesingle{}data/WP\_1990{-}08{-}10{-}25A.txt\textquotesingle{}),}
\NormalTok{ PosixPath(\textquotesingle{}data/NYT\_1991{-}01{-}16{-}A15.txt\textquotesingle{}),}
\NormalTok{ PosixPath(\textquotesingle{}data/WP\_1991{-}01{-}17{-}A1B.txt\textquotesingle{})]}
\end{Highlighting}
\end{Shaded}

Para acomodar os dados, criamos um \texttt{DataFrame} \textbf{vazio} e

nomes das colunas (\texttt{columns}). Determinamos o número de linhas
com a função \texttt{range()}, entre 0 e a quantidade de arquivos
(obtida com \texttt{len()}). Para as colunas, passamos uma lista de
\emph{strings} ao argumento \texttt{columns}:

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Cria um DataFrame e atribui o resultado a variável \textquotesingle{}df\textquotesingle{}}
\NormalTok{df }\OperatorTok{=}\NormalTok{ pd.DataFrame(index}\OperatorTok{=}\BuiltInTok{range}\NormalTok{(}\DecValTok{0}\NormalTok{, }\BuiltInTok{len}\NormalTok{(corpus\_files)), columns}\OperatorTok{=}\NormalTok{[}\StringTok{\textquotesingle{}filename\textquotesingle{}}\NormalTok{, }\StringTok{\textquotesingle{}text\textquotesingle{}}\NormalTok{])}

\CommentTok{\# Chama a variável para inspecionar a saída}
\NormalTok{df}
\end{Highlighting}
\end{Shaded}

\subsection{2. Examinando DataFrames}\label{examinando-dataframes}

Os \texttt{DataFrame}s guardam muita informação, geralmente organizada
em \textbf{colunas}, acessíveis pelo atributo \texttt{columns}:

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Recupera as colunas e seus nomes}
\NormalTok{socc.columns}
\end{Highlighting}
\end{Shaded}

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{Index([\textquotesingle{}article\_id\textquotesingle{}, \textquotesingle{}title\textquotesingle{}, \textquotesingle{}article\_url\textquotesingle{}, \textquotesingle{}author\textquotesingle{}, \textquotesingle{}published\_date\textquotesingle{},}
\NormalTok{       \textquotesingle{}ncomments\textquotesingle{}, \textquotesingle{}ntop\_level\_comments\textquotesingle{}, \textquotesingle{}article\_text\textquotesingle{}],}
\NormalTok{      dtype=\textquotesingle{}object\textquotesingle{})}
\end{Highlighting}
\end{Shaded}

Uma coluna inteira é acessada com colchetes \texttt{{[}{]}}, colocando o
nome da coluna como \emph{string} --- como as chaves de um dicionário.
Vamos recuperar a coluna \texttt{author}:

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\# Recupera o conteúdo da coluna \textquotesingle{}author\textquotesingle{} no DataFrame \textquotesingle{}socc\textquotesingle{}}
\NormalTok{socc[}\StringTok{\textquotesingle{}author\textquotesingle{}}\NormalTok{]}
\end{Highlighting}
\end{Shaded}

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{0         GLOBE EDITORIAL}
\NormalTok{1        Konrad Yakabuski}
\NormalTok{2         Jeffrey Simpson}
\NormalTok{             ...}
\NormalTok{10337      Adam Radwanski}
\NormalTok{10338     GLOBE EDITORIAL}
\NormalTok{Name: author, Length: 10339, dtype: object}
\end{Highlighting}

\begin{warnbox}

\textbf{Segurança (importante no CiberExt):} o formato \emph{pickle}
serializa objetos Python arbitrários e, ao ser \textbf{carregado}, pode
\textbf{executar código arbitrário}. \textbf{Nunca} faça
\texttt{read\_pickle()} (nem \texttt{pickle.load}, \texttt{joblib.load},

\textbf{fontes não confiáveis} --- um \texttt{.pkl} malicioso compromete
a máquina. Use \emph{pickle} apenas com dados que \textbf{você mesmo}
gerou; para intercâmbio entre pessoas/sistemas, prefira formatos que não
executam código, como \textbf{CSV}, \textbf{JSON} ou \textbf{Parquet}
(\texttt{to\_csv}/\texttt{read\_csv},
\texttt{to\_json}/\texttt{read\_json},
\texttt{to\_parquet}/\texttt{read\_parquet}).

\end{warnbox}

\subsection{Resumo da unidade}\label{resumo-da-unidade}

Nesta unidade, você aprendeu a:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{importar} dados para um \texttt{DataFrame} a partir de um
  único arquivo (\texttt{read\_csv()}) ou de vários arquivos
  (\texttt{Path}/\texttt{glob} + laço com \texttt{.at});
\item
  \textbf{examinar} \texttt{DataFrame}s: \texttt{columns}, colunas como
  \texttt{Series}, \texttt{value\_counts()}, \texttt{describe()},
  \texttt{.plot()} e filtragem com \texttt{.loc} e critérios combinados

  evitar o \texttt{SettingWithCopyWarning}, e aplicar funções (do spaCy
  ou próprias) com \texttt{apply()};
\item
  \textbf{extrair} dados com \texttt{tolist()}/\texttt{extend()} e
  \textbf{salvar/carregar} com
  \texttt{to\_pickle()}/\texttt{read\_pickle()}.
